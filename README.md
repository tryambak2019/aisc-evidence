# AISC Evidence

Public evidence repository for the AISC case studies referenced from the portfolio site.

This repository is intentionally small. It contains only the artifacts that are useful for public inspection:

- restored report evidence for the BERT4Rec case study
- the original RL report and notebook used in the portfolio write-up
- minimal helper code where it adds value for technical review

## Structure

- `recsys/` — BERT4Rec capstone report and helper code
- `rl/` — trading-study report and notebook

## Why this repo exists

The portfolio site should not link visitors to private repositories. This repository provides a stable public destination for the specific source artifacts that the site claims are available for inspection.
